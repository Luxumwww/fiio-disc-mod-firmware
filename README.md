# 飞傲 DISC 官改固件

基于官方 **V2.57** 的 SNOWSKY DISC 社区修改固件，为播放器增加 DSP、在线音乐、音频可视化、本机参数调节和 USB 热成像等功能。

**本项目由 Luxumwww 维护，与飞傲官方无隶属关系。“官改”指在官方固件基础上修改，并非官方发布或认证。**

[下载 DISI-02](https://github.com/Luxumwww/fiio-disc-mod-firmware/releases/latest) · [刷写教程](docs/先看教程.pdf) · [源码与构建说明](SOURCE.md) · [反馈问题](https://github.com/Luxumwww/fiio-disc-mod-firmware/issues)

## 下载与刷入

在 Releases 下载 **DISI-02.zip**，完整解压后按包内“先看教程.pdf”操作。GitHub 自动生成的 Source code 压缩包以及 `DISI-02-source.zip` 是源码，不是刷机包。

适用范围：**君正 X2000、256 MiB NAND 的 SNOWSKY DISC，官方 V2.57 兼容基线。**

| 入口 | 用途 |
| --- | --- |
| `01-安装驱动.bat` | 安装 USB 烧录驱动 |
| `02-备份.bat` | 选择系统和功能分区，或全量八分区；读取两遍并核对后保存备份 ZIP |
| `03-刷入.bat` | 校验文件、准备参数并打开 Cloner，由你核对后点“开始” |
| `04-恢复备份.bat` | 选择自己的备份，恢复相应分区 |

**先备份本机，再刷入。** 本包通过 USB Boot / Cloner 刷写主系统和功能分区，会覆盖这些分区中的个人设置和账号；不能当成放入 TF 卡的原厂 OTA 升级包。保留自己的备份并另存一份，不要上传到仓库。两分区包不能替代启动区损坏或整片 NAND 清空后的完整救砖备份。

本次发布已核对镜像、文件校验和组件程序一致性；清理重建后的公开镜像尚未完成整包实机刷入验收。刷写工具不会替你点击“开始”。

## 原厂基础功能

保留官方系统的本地 TF 卡音乐播放、触屏与封面/歌词显示、3.5 mm / 4.4 mm 输出、SBC/LDAC 蓝牙收发、USB DAC 输入、USB 数字音频输出、同轴输出、AirPlay，以及原厂均衡器和 USER 1—10 自定义槽。官改版把部分独立模式入口整合进现有页面或下拉菜单。

原厂硬件和基础功能可参阅 [飞傲产品介绍](https://www.fiio.com/newsinfo/1116375.html) 与 [DISC 功能说明](https://fiio.jp/products/snowsky-disc)。原厂规格不等于本项目对所有格式、手机和外接设备组合的兼容承诺。

## DISI-02 新增与改进

| 类别 | 内容 |
| --- | --- |
| 热成像 | 设置中的工具箱入口；实时画面、伪彩、等比全屏、专属下拉和测温准星修正。**目前仅支持海康 4117** |
| 播放与曲库 | 内嵌封面兼容扩展、指定文件夹排除、ReplayGain 调节与峰值保护 |
| DSP | Haas 立体声、StereoFX 扩展、暖润光泽；本机实例参数调节、单实例恢复默认、SoXR VHQ 降采样设置，以及 Galactic3 银河开启修复 |
| 系统界面 | USB DAC 新主页与真实 PCM 频谱；显示设置、降低白点值、模式切换减闪 |
| 下拉菜单 | USB DAC/蓝牙按键排序、间距统一；收起闪动、误触排序与半展开卡住的修复 |
| 可视化 | 李萨如方向调整、立体声场图、电平与峰值显示；原始/音效后信号切换、高采样率适配与帧率优化 |
| 性能与连接 | 减少重复轮询、文件读取和绘制；优化 EQ/DSP 运算、USB 外接输出重连与调试切换 |
| 二次开发 | 保留可见调试入口：**设置 → 系统设置 → 调试**，不再需要调试解锁文件 |

DSP 降采样只让自有 DSP 在所选采样率处理，再恢复原输出率；原厂 EQ 保持原率。并非所有档位和音效组合都会降低 CPU 占用。

## 从 DISI-01 延续的功能

### 音效、均衡器与手机控制

- 音乐厅氛围、压限器、仿电子管、V8 混响、PurestWarm3 暖声、Dragonfly 混响、Galactic3 混响等效果。
- DSP 开关、排序和预设；纯音、蓝牙接收、USB DAC、在线音频共用配置。
- 支持独立音效实例、重复添加、调参、旁路、排序和移除，以及声场、延迟、去齿音、动态 EQ、参量 EQ/滤波器等模块。
- Android 配套控制 App 经 BLE 调节 DSP 和原厂 USER 1—10 均衡器槽；设置自动保存并回读，命名预设可存入播放器脱离手机调用。
- 蓝牙设置保留 BLE 控制开关。**配套 Android App 需要另外安装，本刷机包不含 APK。**

### 蓝牙、USB 与音频可视化

- LHDC V5 **接收**、左右电平与格式信息；完善 LDAC/LHDC 档位显示，不代表增加了所有蓝牙编码协议或 LHDC 发送。
- 进入蓝牙接收时按原状态管理 Wi-Fi，减少共用 2.4 GHz 天线干扰；明确手动开启后尊重用户操作。
- 纯音下拉 USB 输出、蓝牙接收输出到 USB 小尾巴；独立音量记忆与切换保护，USB 输出详情和手动重连。
- 李萨如图、二维傅里叶万花筒、极坐标、径向傅里叶频谱等，支持相关模式下的手势切换、旋转和幅度归一化。
- USB DAC 的音频信息、DSP、均衡器、旋转和可视化入口，以及 PCM/DoP 信息显示改进。

### 在线音乐、缓存与下载

- 网易云音乐、QQ 音乐、酷狗音乐入口，支持扫码登录、搜索及平台实际提供的收藏、歌单和推荐。
- 独立播放页、封面、歌词、队列、播放模式、拼音输入和下一曲预加载；收起后可继续播放，从下拉卡片返回。
- 可用音质选择与回退、单曲和批量下载；下载确认、进度及可获取的封面、歌词和标签补充。
- TF 卡使用“在线音频缓存”和“流媒体下载”目录，按平台分类；缓存特殊后缀避免混入纯音曲库。
- 功能可用性及音质受平台接口、账号权限和网络影响；本项目不提供会员权限或音乐授权。

### 系统与日常操作

- 纯音下拉 DSP/USB 快捷入口、整页滚动、长按编辑和拖动排序；返回页面、状态栏、遮罩及动画等修复。
- 最多 20 个 Wi-Fi 网络保存、手动连接、查看密码和删除。
- 个人数据备份/恢复、多备份管理、内部和 TF 空间查看、模块安装更新与启停。
- 自动校时补救、多授时源、备用 DNS 与 RTC 写回；保留原厂自动时间开关。
- FPU 计算、DPU 合成、后台减负与存储写入优化。

01 版原始清单见 [DISI-01 功能清单](docs/DISI-01-功能清单.txt)，本次原始增量见 [DISI-02 新增功能](docs/DISI-02-新增功能.txt)。以上按最终保留的功能合并，不把中间实验版当作当前功能。

## 当前限制

- 热成像退出后偶发重新打开无画面的问题尚未完全解决；主机侧完整最高/最低/中心温度覆盖显示尚未完成，全屏裁切会裁去部分相机自带文字。
- 保持原厂 **60 Hz**；74/80/90 Hz 高刷试验已撤回，不属于本包功能。可视化也不保证所有场景稳定 60 fps。
- 高采样率叠加 EQ/多个 DSP 仍可能卡顿或失真；多 DSP 性能未做全面验收。
- 特定 USB 小尾巴兼容问题仍可能存在；此前撤回的 USB DAC 接收生命周期实验补丁没有重新加入。
- USB DoP/DSD 的全部组合和长期稳定性未得到全面确认。

## 发布包与隐私

DISI-02 基于 2026-10-26 的最新备份，保留 Host/UI 220、DSP 1.17.0 及热成像等组件。原有启用和禁用标记按备份保留，不强行打开所有插件。

发布镜像已清理个人账号、Wi-Fi 凭据、蓝牙配对/连接记录、日志、音乐缓存与播放记录、SN/MAC 缓存。DSP 参数、原厂 EQ 自定义槽和界面偏好保留，初始音量设为 0；USB/无线调试开关默认关闭，入口可见。此清理不会擦除刷入者自己的硬件身份分区。

教程、说明和许可文件不参与刷机工具的必需文件校验；自行删除说明文件不会阻止工具运行。
